# Hồ Thủy Sinh Chữa Lành (3D Zen Aquascape Sanctuary)

Không gian nuôi cá **Betta & Guppy 3D** thư giãn ngay trên trình duyệt (PC & Điện thoại) — tự tay chọn nền cát, xếp đá Seiryu, đặt gốc lũa, trồng cây thủy sinh, cho cá ăn, thay nước và nghe âm thanh lọc thác ASMR chữa lành.

## Tính năng chính
- **3 Bố cục mẫu & Chế độ Tự Build Bể 3D**: Hỗ trợ lưới tỷ lệ vàng, kéo thả/xoay/phóng to vật thể trực tiếp trên nền cát.
- **Vật liệu PBR & Quang học dưới nước**: Vân đá Seiryu, vỏ lũa cổ thụ, cát suối tự nhiên, tia nắng xuyên mặt nước (God-Rays) và hiệu ứng hậu kỳ Bloom.
- **Tích hợp mô hình `.GLB` / `.GLTF` riêng**: Nạp trực tiếp file `.glb` từ máy hoặc cấu hình cố định trong `public/models/manifest.json`.
- **Chăm sóc & Thư giãn**: Cho ăn 3 loại mồi, thay 30% nước, lau kính, kè gương cá Betta, 5 chế độ đèn WRGB/Hoàng hôn/Ánh trăng, mixer âm thanh ASMR và đồng hồ Pomodoro 25 phút.
- **Tương thích mọi thiết bị**: Tự động căn khung hình 3D và thanh công cụ mượt mà trên cả màn hình dọc điện thoại lẫn màn hình rộng PC.

## Chạy thử trên máy cá nhân

```bash
npm install
npm run dev
```

## Triển khai GitHub Pages
Repo đã tích hợp sẵn `.github/workflows/deploy.yml`. Chỉ cần vào **Settings → Pages → Build and deployment → Source: GitHub Actions**, mỗi lần push lên nhánh `main` trang web sẽ tự động build và xuất bản.
